# Android App

Flutter-приложение для кассовой системы.

## Что уже есть

- `Главная`
- `Касса`
- `Поступления`
- `Номенклатура`
- `Отчет`
- `Очередь печати`

## Запуск

```bash
flutter pub get
flutter run
```

## Backend URL

По умолчанию приложение использует `http://10.0.2.2:5000`. Это адрес для Android-эмулятора.

Для физического устройства запускайте с `--dart-define`:

```bash
flutter run --dart-define=API_BASE_URL=http://192.168.1.10:5000
```

Если backend работает на другом порту, просто укажите его в URL.

## Порядок быстрой проверки

1. `Главная`
   Проверить, что загружаются статистика, последние поступления и товары с малым остатком.
2. `Поступления`
   Проверить список, поиск и открытие деталей документа.
3. `Номенклатура`
   Проверить поиск, остатки, цены и штрихкоды.
4. `Касса`
   Найти товар, добавить в корзину, сменить режим продажи, сменить оплату, оформить чек.
5. `Отчет`
   Проверить сводку без фильтра и с диапазоном дат `YYYY-MM-DD`.
6. `Очередь печати`
   Проверить, что после действий в кассе задания появляются и имеют ожидаемый статус.

## На что смотреть в smoke-тесте

- ошибки сети, `connection refused`, `timeout`
- пустые списки там, где на backend точно есть данные
- расхождение сумм между `Поступления`, `Касса` и `Отчет`
- ошибки на пустых или частично заполненных ответах API
